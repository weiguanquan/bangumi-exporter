命令行用法：
  不带任何参数运行            = 启动 Web 界面（和 --serve 一样）
  python -m bangumi_exporter.cli --serve              启动 Web 界面
  python -m bangumi_exporter.cli --gui                启动原生界面
  python -m bangumi_exporter.cli --type anime -f csv  导出动画到 CSV
  python -m bangumi_exporter.cli --type all -f all    导出全部类型与格式
  python -m bangumi_exporter.cli --list-sources       探测并列出所有数据源
  python -m bangumi_exporter.cli --source URL         手动指定数据源
  python -m bangumi_exporter.cli --incremental        只导出有变化的条目
  python -m bangumi_exporter.cli --offline            离线重新生成文件
  python -m bangumi_exporter.cli --since 7d           只导出最近 7 天的更新
  python -m bangumi_exporter.cli --no-details         跳过详情补取（更快）

  ── v3.2 新命令 ──
  python -m bangumi_exporter.cli -f all --recommend --report --archive --supplement
                                                      全套：推荐+报告+归档+数据补全
  python -m bangumi_exporter.cli --supplement          只做数据补全（简介/staff/声优/分集）
  python -m bangumi_exporter.cli --supplement-limit 5  只补前 5 条（先试速度）
  python -m bangumi_exporter.cli --no-profile         不生成画像（默认生成）

  python -m bangumi_exporter.cli --history            列出快照并对比最近两份
  python -m bangumi_exporter.cli --compare 旧ID 新ID   对比指定的两份快照
  python -m bangumi_exporter.cli --watch 30m          定时导出（30m/6h/1d）
  python -m bangumi_exporter.cli --token TOKEN --account 主号
                                                      保存账号
  python -m bangumi_exporter.cli --use-account 主号    切换账号
  python -m bangumi_exporter.cli --accounts           列出所有账号
  python -m bangumi_exporter.cli --del-account 主号    删除账号

  才会执行导出；否则程序会认为你想打开 Web 界面。

Token 获取：
  登录 bgm.tv → 设置 → App 授权 → 创建应用 → 复制 Access Token

常见问题：
  提示「Token 无效或已过期」：只有所有数据源都返回 401 才会这样提示，
    此时确实需要重新生成 Token。
  提示「无法连接任何 Bangumi 数据源」：先在「设置 → 数据源」点「重新探测」，
    若全部不可用，请在「设置」里填写 HTTP 代理（例如 http://127.0.0.1:7890）。
  「平台」列是空的：需要开启「补全平台等详情」（默认开启）。
  「我的评分 / 我的短评 / 我的标签」是空的：这几列是「你自己在 Bangumi 上填的」，
    站外接口不会替你编造。导出时的「数据体检」会明确标出这几列属于「用户自有」。
  「看到第几集」全是 0：同上，属于你自己记录的观看进度。
  「条目标签」为空：升级到 v3.2 后联网导出一次即可（旧缓存没有这一列），
    之后离线导出也能正常显示。
  「卷数」为空：卷数是书籍/漫画才有的字段，动画没有卷数，属正常。
  「制作公司 / 放送星期 / 简介」为空：需要在「导出」页勾选「数据补全」
    （或命令行加 --supplement）。放送星期只有仍在播 / 有排期的条目才有。
  增量导出说「没有任何变化，未生成文件」：这是正常的，说明收藏没有变化。
  定时导出没反应：--watch 模式下每轮都会导出，只有检测到变化才写提醒。
  启动失败：查看 输出\launch.log。
